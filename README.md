REST API Client using Java

This project is a simple Java-based REST API Client developed as part of the CODTECH Internship Task-2. The main purpose of this project is to understand how Java applications communicate with public REST APIs and display real-time data in a structured format.In this project, the REST Countries API is used to fetch information about countries. The user enters the name of a country in the console, and the application sends an HTTP GET request to the API server. The API returns the response in JSON format, and the program parses the JSON data to extract useful information such as country name, capital city, population, and currency.

The project is developed using Java and Eclipse IDE. It uses core Java classes like HttpURLConnection, BufferedReader, InputStreamReader, and Scanner for handling HTTP requests and user input. The org.json library is used to parse JSON responses easily.One of the important features of this project is that it displays the data in a clean and readable format instead of showing raw JSON data. The application also includes exception handling to manage errors like invalid country names or connection issues.

This project helped in learning important concepts such as REST API integration, HTTP request handling, JSON parsing, exception handling, and external library configuration in Java. It also provided practical experience in working with real-time APIs and handling API responses.

🌟Features:
* Fetches real-time country information
* Uses public REST API
* Sends HTTP GET requests
* Parses JSON response data
* Displays structured output
* Handles invalid input and errors
